# DSR ENERGY x CURRENCY CASE STUDY

DS / ML project. Emphasis on API maintenance and ETL, Exploratory Data Analysis and and Machine Learning Prediction.

QUESTION: “To what extent could asymmetrical Solar and Electrical energy weighting help model West African currency stability by a 2030 based scenario?”

API / Datasets: UNCom Trade, DBNomics and WB API

Tech Stack: Python, SQL, NashPy, SKlearn, Stats Model (data cleaning, intro / intermediate statistics + game theory, ML models)

Fetched data on bilateral trade and macroeconomic indicators and automated the ETL/LT process — I have pulled descriptive stats and used the Trade Dependency Index to base a narrower range of insights. Aim: create a predictive model and game theoretic scenario by end of November


Future culmination with a simpler, preceding EDA and Visualisation project into a Clouflare and AWS hosted website + series of dashboards via a JSON / API bridge
